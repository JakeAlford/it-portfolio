HomeLab Manager

As the home lab grew, I wanted one place to keep track of devices and eventually control the systems behind them. Rather than just sketching an idea, I started building the app and backend.

In developmentIndependent project
Why I did it

Make an Android management app that can grow from inventory and account management into secure infrastructure controls.

What I configured / built
  • Built Android screens in Kotlin and Jetpack Compose for phones and tablets.
  • Created a C# ASP.NET Core (.NET 10) API with SQLite identity storage.
  • Implemented administrator bootstrap, login, mandatory password changes for new users and user-management functions.
  • Used Postman and automated API tests to check authentication and administrator workflows.
What I verified
  • A recorded backend test run passed all 55 automated API tests.
  • Administrator bootstrap and first-login password-change flows were tested.
What I learned

This has taught me a lot about keeping a user interface separate from a backend, testing the important flows and thinking about access control properly.

Current status / next steps

Keep building the integrations and test the app against real home-lab services. Not all intended monitoring and remote controls are implemented yet.

This is personal project experience, not a claim of paid IT employment. I keep working systems, locally tested features and plans clearly separated.
