Android TV control centre

I also wanted a dashboard that I could use from the sofa, where a normal touch-screen interface wouldn't make sense.

Working prototypeIndependent project
Why I did it

Build a TV-friendly interface for the home lab with clear navigation and room for future monitoring and controls.

What I configured / built
  • Built a Google TV-style Android TV layout with separate navigation for home-lab sections.
  • Tested an app build on Chromecast 4K hardware and worked through Android TV compatibility issues.
What I verified
  • Remote-friendly navigation and an app build were tested on physical hardware.
What I learned

Testing on a real device has shown me limitations that are easy to miss in an emulator.

Current status / next steps

Live hardware telemetry, service controls and Wake-on-LAN remain planned features, not completed integrations.

This is personal project experience, not a claim of paid IT employment. I keep working systems, locally tested features and plans clearly separated.
