Infrastructure / CASE STUDY

Windows Server & Hyper-V

I wanted one reliable machine where I could run different services without everything depending on the same operating system. That became the starting point for most of my other projects.

OperationalIndependent project
Why I did it

Build a practical home lab with enough separation to learn how virtual machines, networking and services fit together.

What I configured / built
  • Installed Windows Server 2022 Datacenter on a Dell OptiPlex 3040 Mini Tower with an Intel i5-6600.
  • Configured Hyper-V networking and separate Debian VMs for Pi-hole and Uptime Kuma.
  • Set up SSH administration for Linux services and checked VM connectivity and service reachability.
What I verified
  • Pi-hole and Uptime Kuma were running on separate Debian virtual machines.
  • Remote SSH administration was tested as part of the home-lab setup.
What I learned

Separating services makes it easier to make changes and work out exactly where a problem is coming from.

Current status / next steps

Keep documenting the configuration and improve backup and recovery testing.

This is personal project experience, not a claim of paid IT employment. I keep working systems, locally tested features and plans clearly separated.
