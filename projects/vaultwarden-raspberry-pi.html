Vaultwarden on Raspberry Pi

I wanted to host something I would actually use every day, rather than install a service purely for a test.

OperationalIndependent project
Why I did it

Set up a small Linux device to host a useful service with sensible account security.

What I configured / built
  • Deployed Vaultwarden on a Raspberry Pi Zero 2 W.
  • Configured administration, accounts and two-factor authentication.
  • Checked password synchronisation across personal devices and added availability monitoring.
What I verified
  • Cross-device synchronisation worked during testing.
  • The service was monitored as part of the home lab.
What I learned

Self-hosting means taking responsibility for service availability and recovery, not just getting the application to start.

Current status / next steps

Complete a proper backup and recovery test; that work is still outstanding.
