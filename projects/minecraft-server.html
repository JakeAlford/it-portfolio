Server hosting / CASE STUDY

Minecraft server hosting

I wanted to host Minecraft for friends and use it as a way to learn more about running a service that other people connect to.

Locally tested / stoppedIndependent project
Why I did it

Set up a game server in its own VM, test how it behaves and work out what needs doing before inviting friends to connect remotely.

What I configured / built
  • Set up a Debian 13 Hyper-V VM with Java and the Paper server.
  • Configured a systemd service, firewall rules, a six-player whitelist, a DHCP reservation and RCON access protected through SSH.
  • Added monitoring and Discord alerts, then checked local connectivity and performance.
What I verified
  • Joined successfully from the local network.
  • Observed 20 TPS during a one-player test, not a six-player load test.
What I learned

Getting a server working on the LAN is different from making it securely reachable from the internet, especially behind an ISP-controlled gateway.

Current status / next steps

The server was deliberately stopped on 19 November 2026 while I investigated FibreNest external-access restrictions. External access and six-player testing have not been confirmed.

This is personal project experience, not a claim of paid IT employment. I keep working systems, locally tested features and plans clearly separated.
